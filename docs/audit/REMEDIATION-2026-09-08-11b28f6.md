# Remediation record — V12 audit of `11b28f6`

External audit: [V12](https://v12.sh/), scope `mihailShumilov/covantic@11b28f6`, 26 findings
(1 Critical, 8 High, 3 Medium, 14 Low). This record maps each finding to the change that closes
it and the test that pins it. Findings are numbered in the order the report lists them.

Every fix ships in one program upgrade. Two account types grew (`GovernanceBaseline`,
`PolicyAuthorityCheckpoint`) and gained migration instructions; `RiskAttestation` grew and is
covered by the existing `migrate_attestation`; `InsurancePolicy` did not change. Two new PDAs are
written by the purchase (`PolicyAuthorityCheckpoint`, `PolicyPriceTerms`).

## Operational notes for the upgrade

- Run `pnpm gov:migrate` once after the program upgrade. The authority crank also grows an
  undersized checkpoint on its own, and the attestation publisher already grows an undersized
  attestation.
- Existing policies have no `PolicyPriceTerms`; their oracle-manipulation claims plan
  `unprovable` and go to review. New purchases carry terms whenever the agent has a priced habit.
- Existing policies have no purchase-time authority reading; the crank's first reading is
  predecessor-less, so a takeover that lands before the crank's second tick after the upgrade is
  not provable and goes to review.
- The web IDL was regenerated (`pnpm idl:sync`). The TypeScript SDK in `covantic-solana-sdk` still
  exposes `verifyAndPayout` and needs a release that removes it.
